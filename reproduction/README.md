# Reproduction

This directory contains the results and scripts used to reproduce the figures and tables reported in the DARUMA-binding manuscript.

## Directory structure

- `results/caid2/`: DARUMA-binding prediction results for CAID 2.
- `results/caid3/`: DARUMA-binding prediction results and per-protein CSV files for CAID 3.
- `results/occlusion_analysis/`: Results of the occlusion analysis.
- `scripts/`: Scripts for reproducing the figures and tables in the manuscript.

## Scripts

- `figure_2.py`
- `figure_3.py`
- `figure_4.py`
- `figure_S1.py`
- `table_1.py`
- `table_2.py`
- `table_3.py`
- `table_S1.py`
- `table_S2.py`

Each script uses the corresponding files in the `results/` directory.
